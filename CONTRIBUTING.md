# Contributing

Bug reports and reproducible test results are welcome.

When reporting vehicle behavior, include:

- vehicle classname or displayed name;
- map and approximate coordinates;
- road and weather conditions;
- gear used;
- approximate starting speed;
- speed at the steepest point;
- whether the vehicle was loaded;
- other vehicle-related mods enabled.

Pull requests should:

- keep changes limited to the stated vehicle;
- preserve unrelated approved configurations;
- avoid third-party proprietary assets;
- pass configuration and signature validation;
- explain the expected gameplay effect;
- include an in-game test result.

Do not submit private signing keys, compiled PBO files, crash dumps, server
profiles or private server configuration.
